# Security Policy

## Supported versions

Security fixes are provided for the latest release on the default branch.

## Report a vulnerability

Use [GitHub Private Vulnerability Reporting](https://github.com/gezi71/release-front-page/security/advisories/new). Do not open a public issue for an undisclosed vulnerability and do not attach private repositories, credentials, tokens, author emails, or exploit details to ordinary issues.

Include the affected command, a minimal synthetic reproduction, impact, and any proposed mitigation. Maintainers will coordinate disclosure after confirming the report.
